# Windows Liquid Glass Theme v1.0.0

The first stable release of Windows Liquid Glass Theme.

Transform the Windows 11 desktop into a unified Liquid Glass-inspired environment with translucent surfaces, rounded panels, custom styling, and coordinated desktop components.

## Features

### Windows Customization
- Windows 11 Taskbar styling
- Start Menu customization
- File Explorer styling
- Translucent Windows effects
- Taskbar height and icon size customization
- Taskbar dock animation

### Desktop Experience
- YASB custom desktop top bar
- Fluent Flyouts customization
- Custom JetBrains Mono Nerd Font

### Spotify Themes
- **Liquid Glass:** Dark translucent panels, floating surfaces, and subtle glass effects.
- **Misty Forest:** Green-tinted glass surfaces, mint accents, and enhanced blur.
