# Credits & Attribution

The Windows Liquid Glass Theme is a personal customization project that
combines configurations for several third-party Windows customization
tools and applications.

This repository does not claim ownership of the third-party software
listed below.

---

# Windows Customization

## Windhawk

Windhawk provides the framework used for several Windows UI
customizations in this project.

1. [Official website](https://windhawk.net/)

2. [GitHub](https://github.com/ramensoftware/windhawk)

Used for:
- Windows 11 Taskbar Styler
- Windows 11 Start Menu Styler
- Windows 11 File Explorer Styler
- Translucent Windows
- Taskbar Dock Animation
- Taskbar height and icon size

---

# Windows 11 Styling Guides

The project uses concepts and styling configurations based on the
Windows 11 customization work and documentation provided by the
Windhawk/ramensoftware community.

1. [Windows 11 Taskbar Styling Guide](https://github.com/ramensoftware/windows-11-taskbar-styling-guide)

2. [Windows 11 Start Menu Styling Guide](https://github.com/ramensoftware/windows-11-start-menu-styling-guide)

These projects provide documentation and examples for customizing
Windows 11 XAML-based UI components.

---

# YASB

YASB (Yet Another Status Bar) is used for the custom top bar.

1. [Official GitHub](https://github.com/amnweb/yasb)

2. [Installation documentation](https://github.com/amnweb/yasb/wiki/Installation)

This repository includes a customized YASB configuration and
stylesheet.

---

# Spicetify

Spicetify is used to customize the Spotify desktop application.

1. [Official website](https://spicetify.app/)

2. [GitHub](https://github.com/spicetify/cli)

This repository includes custom Spotify color and CSS configuration
files designed for the Liquid Glass appearance.

---

# Fluent Flyouts

Fluent Flyouts is used for customized Windows media and system flyouts.

1. [GitHub](https://github.com/unchihugo/FluentFlyout)

This repository includes a customized Fluent Flyouts settings file.
