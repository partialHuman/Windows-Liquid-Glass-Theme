# Changelog

All notable changes to Windows Liquid Glass Theme are documented in this file.

## [Unreleased]

## [1.1.0] - 2026-11-24

### Added
- Visible mint-accented keyboard focus indicators for interactive controls.
- Keyboard-focus feedback for Spotify track rows and cards.
- Selected-track visual treatment.
- Subtle press feedback for frequently used buttons.
- Reduced-motion support respecting the operating system preference.

### Improved
- Interaction consistency across navigation, cards, track lists, and action controls.
- Keyboard accessibility while preserving the existing Misty Forest glass appearance.

## [1.0.0] - 2026-11-24

### Added
- Misty Forest Spotify theme with green-tinted glass surfaces and mint accents.
- Individual preview images for the Liquid Glass and Misty Forest Spotify themes.
- Installation, requirements, configuration, and troubleshooting documentation.

### Changed
- Organized the existing Spotify Liquid Glass theme into its own directory.
- Updated the README with separate Spotify theme previews and project information.
- Improved and expanded project documentation.

### Documentation
- Added detailed installation instructions.
- Expanded configuration references.
- Added troubleshooting guidance.
